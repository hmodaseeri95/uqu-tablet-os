# UQU Tablet OS

واجهة ويب تفاعلية تحاكي نظامًا لوحيًا لطلاب جامعة أم القرى. أول دخول يعرض كلمة مرحبا ببطء، ثم يسأل عن الاسم والرقم الجامعي واللون المفضل. بعد ذلك يقدر الطالب يعدّل جدوله ومهامه واسمه، وتصل مهام من الدكاترة أثناء الاستخدام.

## التشغيل محليًا

افتح `index.html` في المتصفح، أو شغّل خادمًا بسيطًا من مجلد المشروع:

```bash
python -m http.server 8765
```

ثم ادخل إلى `http://127.0.0.1:8765`.

تعليم أي مهمة يحدّث النسبة والدائرة وعدد المهام المكتملة والمتبقية، وتُحفظ الحالة في المتصفح.
