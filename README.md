# UQU Tablet OS

واجهة ويب تفاعلية تحاكي نظامًا لوحيًا لطلاب جامعة أم القرى. تجمع الشاشة مؤشر إنجاز اليوم، قائمة المهام، وتنبيهات SMS العاجلة في مكان واحد.

## التشغيل محليًا

افتح `index.html` في المتصفح، أو شغّل خادمًا بسيطًا من مجلد المشروع:

```bash
python -m http.server 8765
```

ثم ادخل إلى `http://127.0.0.1:8765`.

تعليم أي مهمة يحدّث النسبة والدائرة وعدد المهام المكتملة والمتبقية، وتُحفظ الحالة في المتصفح.

## الاستضافة على Render

المستودع يحتوي `render.yaml` لموقع ثابت. من لوحة Render اختر Blueprint ثم اربط هذا المستودع، أو استخدم:

[Deploy to Render](https://render.com/deploy?repo=https://github.com/hmodaseeri95/uqu-tablet-os)
